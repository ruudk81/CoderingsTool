# Step 1 PreProcessor — Cache Logic

## Cache Type: Growing Model

Step 1 produces a **growing model** (`List[PreprocessedModel]`) — per-respondent data with cleaned text and quality filter flags. No metadata cache is produced.

Storage: SQLite-backed with pickle serialization. Filename pattern: `{prefix}_{step}_{datafile}_{variable_key}.pkl`

## Input Files

| Step name | Prefix | Model class | Type | Method | Contents |
|-----------|--------|-------------|------|--------|----------|
| `"data"` | 001 | `ResponseModel` | Growing (List) | `load_from_cache()` | Per-respondent raw responses with respondent_id, response, response_type |

## Output Files

| Step name | Prefix | Model class | Type | Method | Contents |
|-----------|--------|-------------|------|--------|----------|
| `"preprocessed"` | 002 | `PreprocessedModel` | Growing (List) | `save_to_cache()` | Per-respondent cleaned text with quality_filter, quality_filter_code |

## Cache Key Scheme

```
Variable key: generated by generate_enhanced_variable_key(selected_variables, is_merged, sample_size)
              e.g., "Q20_500" or "Q1_1+Q1_2_concat_semicolon_skip_full"

Growing model file: 002_preprocessed_{datafile}_{variable_key}.pkl

SQLite key:   (filename, "preprocessed", variable_key)
```

## Cache-Hit Logic

```python
# In run_experiment.py, force_recalc is True by default (development mode)
# In pipeline.py, cache is checked before running:
if not force_recalc and cache_manager.is_cache_valid(filename, "preprocessed", variable_key):
    preprocessed = cache_manager.load_from_cache(filename, "preprocessed", variable_key, PreprocessedModel)
    if preprocessed:
        return preprocessed

# Otherwise: run full pipeline
raw_text = cache_manager.load_from_cache(filename, "data", variable_key, ResponseModel)
preprocessed = run_preprocessing(raw_text)  # TextNormalizer → SpellChecker → TextFinalizer
cache_manager.save_to_cache(preprocessed, filename, "preprocessed", variable_key, elapsed_time, var_lab=var_lab)
```

## Growing Model Assembly

The growing model is assembled in `run_experiment.py` after all three stages complete:

1. **Type split**: separate string vs non-string responses
2. **Process strings**: normalize → spell check → finalize → `processed_map` (respondent_id → item)
3. **Merge non-strings**: add to `processed_map`
4. **Iterate original order** (`raw_text_list`):
   - Look up processed item by respondent_id
   - Set `quality_filter_code` for NaN (`99999998`) and code values (`99999997/98/99`)
   - Set `quality_filter = True` for filtered items
   - Create `PreprocessedModel` for missing items with `<NA>` response
5. **Save**: `cache_manager.save_to_cache(preprocessed_text, filename, "preprocessed", variable_key)`

## Data Flow

```
Step 0 cache (prefix 001)
  └─ data (growing)                    ──→ [Step 1 input: raw responses]
                                            │
                                   TextNormalizer → SpellChecker → TextFinalizer
                                            │
                                            ▼
Step 1 cache (prefix 002)
  └─ preprocessed (growing)            ──→ [Step 2 reads this: cleaned text with quality flags]
```
