# Step 2 — Cache Logic

## Cache Type: Growing Model

Step 2 produces a **growing model** (`List[QualityFilteredModel]`) — per-respondent data with LLM quality grading results. No metadata cache is produced.

Storage: SQLite-backed with pickle serialization. Filename pattern: `{prefix}_{step}_{datafile}_{variable_key}.pkl`

## Input Files

| Step name | Prefix | Model class | Type | Method | Contents |
|-----------|--------|-------------|------|--------|----------|
| `"preprocessed"` | 002 | `PreprocessedModel` | Growing (List) | `load_from_cache()` | Per-respondent cleaned text with quality_filter, quality_filter_code from step 1 |

## Output Files

| Step name | Prefix | Model class | Type | Method | Contents |
|-----------|--------|-------------|------|--------|----------|
| `"quality_filter"` | 003 | `QualityFilteredModel` | Growing (List) | `save_to_cache()` | Per-respondent with updated quality_filter, quality_filter_code from LLM grading |

## Cache Key Scheme

```
Variable key: generated by generate_enhanced_variable_key(selected_variables, is_merged, sample_size)
              e.g., "Q20_500" or "Q1_1+Q1_2_concat_semicolon_skip_full"

Growing model file: 003_quality_filter_{datafile}_{variable_key}.pkl

SQLite key:   (filename, "quality_filter", variable_key)
```

## Cache-Hit Logic

```python
# In run_qualityFilter.py, force_recalc is True by default (development mode)
# In pipeline.py, cache is checked before running:
if not force_recalc and cache_manager.is_cache_valid(filename, "quality_filter", variable_key):
    filtered = cache_manager.load_from_cache(filename, "quality_filter", variable_key, QualityFilteredModel)
    if filtered:
        return filtered

# Otherwise: run quality filtering
preprocessed = cache_manager.load_from_cache(filename, "preprocessed", variable_key, PreprocessedModel)
grader = Grader(preprocessed, var_lab, verbose, prompt_printer)
quality_filtered = grader.grade()
cache_manager.save_to_cache(quality_filtered, filename, "quality_filter", variable_key, elapsed_time, var_lab=var_lab)
```

> **Current state:** `force_recalc=True` is the default in `StepConfig`. The cache-hit path above is never exercised in normal use. The pipeline always re-runs step 2.

## Growing Model Assembly

The growing model is assembled inside `Grader.grade()`:

1. **Pre-filter empties**: empty/None/NaN responses → mark `99999998`
2. **Separate**: `quality_filter_code is not None` → passthrough; `None` → LLM grading
3. **LLM grading**: remaining responses graded individually → `{respondent_id → quality_filter_code}`
3. **Merge**: build `QualityFilteredModel` for each input response:
   - Pre-filtered: keep existing quality_filter_code
   - LLM-graded: apply category → code mapping
   - Meaningful (null category): quality_filter=False, quality_filter_code=None
4. **Save**: `cache_manager.save_to_cache(quality_filtered, filename, "quality_filter", variable_key)`

## Data Flow

```
Step 1 cache (prefix 002)
  └─ preprocessed (growing)            ──→ [Step 2 input: cleaned text with step 1 flags]
                                            │
                                    Grader (per-response LLM quality assessment)
                                            │
                                            ▼
Step 2 cache (prefix 003)
  └─ quality_filter (growing)          ──→ [Step 3 reads this: filters to meaningful responses]
```

## Downstream Consumers

- **Step 3** loads `List[QualityFilteredModel]` — filters to `quality_filter=False` (meaningful responses) for idea extraction
- **Step 7** (export) loads `List[QualityFilteredModel]` — for quality filter statistics sheet in Excel output
