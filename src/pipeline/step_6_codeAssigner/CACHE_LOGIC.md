# Step 6 Code Assigner — Cache Logic

## Cache Type: Growing Model

Step 6 produces a **growing model** (`List[CodeAssignedModel]`) — per-respondent data with code assignments. This is the final pipeline output consumed by step 7 (export).

Storage: SQLite-backed with pickle serialization. Filename pattern: `{prefix}_{step}_{datafile}_{variable_key}.pkl`

## Input Files

| Step name | Prefix | Model class | Type | Method | Source |
|-----------|--------|-------------|------|--------|--------|
| `"taxonomy_classified"` | 005 | `TaxonomyClassifiedModel` | Growing (List) | `load_from_cache()` | Step 4 — enriched ideas with facet/attribute/partition (preferred) |
| `"extracted_ideas"` | 004 | `IdeasExtractedModel` | Growing (List) | `load_from_cache()` | Step 3 — raw ideas (fallback if step 4 cache missing) |
| `"mece_codes"` | 006 | `CodingResultsCache` | Metadata (single) | `load_metadata_from_cache()` | Step 5 — codebook (raw_codes), partition_set, partition_results |
| `"extracted_ideas"` | 004 | `ExtractionMetadata` | Metadata (single) | `load_metadata_from_cache()` | Step 3 — survey_question, language, specifiers |

### Ideas Loading Priority

The dev runner (`run_experiment.py`) loads ideas with fallback:

```python
ideas_models = load_step4_enriched()           # Try step 4 growing model first
if ideas_models is None:
    print("Step 4 growing model not cached, falling back to step 3")
    ideas_models = load_step3_ideas()           # Fall back to step 3
```

The production pipeline (`pipeline.py`) passes `enriched_text or encoded_text` from the main flow.

## Cache Key Scheme

```
Variable key: generated by generate_enhanced_variable_key(selected_variables, is_merged, sample_size)

Growing model file: 007_taxonomy_codes_{datafile}_{variable_key}.pkl

SQLite key:   (filename, "taxonomy_codes", variable_key)
```

Note: step 6 checks the growing model directly (no `_metadata` suffix), unlike steps 4-5 which check metadata.

## Cache-Hit Logic

```python
# Check growing model cache
if not force_recalc and cache_manager.is_cache_valid(filename, step_name, variable_key):
    assigned_results = cache_manager.load_from_cache(filename, step_name, variable_key, CodeAssignedModel)
    if assigned_results:
        return assigned_results
```

## Growing Model Assembly (`_build_output_models()`)

The growing model is assembled **once** after all LLM assignments complete — it is not incremental. The process in `CodeAssigner._build_output_models()`:

1. **Collect assignments**: `assignment_lookup: Dict[idea_id → CodeAssignment]` from all worker results
2. **Resolve code IDs to labels**: per-task resolution (from embedding pre-filter scoped IDs) or global resolution (from full codebook IDs)
3. **Iterate all original ideas** (from `self._ideas_models`):
   - For each response → idea:
     - Get assignment from lookup (or None for unassigned)
     - Get resolved label (or `"__UNASSIGNED__"`)
     - Build `CodeAssignedSubmodel` with:
       - All inherited fields from input idea (domain, facet, attribute, partition_name, abstraction ladder)
       - `assigned_code` = resolved code label
       - `assigned_attribute` = from pre-assigned attribute map (step 4)
       - `confidence` = assignment confidence (0.0 if unassigned)
       - `rationale` = assignment rationale (or "No assignment from LLM")
       - `partition_name` = from idea's domain (normalized)
   - Wrap in `CodeAssignedModel` preserving response structure

4. **Save**: `cache_manager.save_to_cache(assigned_results, filename, "taxonomy_codes", variable_key)`

## Data Flow

```
Step 3 cache (prefix 004)
  ├─ extracted_ideas (growing)         ──→ [Step 6 fallback: raw ideas if step 4 cache missing]
  └─ extracted_ideas_metadata          ──→ [Step 6 input: survey context]

Step 4 cache (prefix 005)
  └─ taxonomy_classified (growing)     ──→ [Step 6 preferred input: enriched ideas]

Step 5 cache (prefix 006)
  └─ mece_codes_metadata               ──→ [Step 6 input: codebook + domain context]
                                            │
                               P10 code assignment (per idea)
                               + output model assembly
                                            │
                                            ▼
Step 6 cache (prefix 007)
  └─ taxonomy_codes (growing)          ──→ [Step 7 reads this: final export data]
```
